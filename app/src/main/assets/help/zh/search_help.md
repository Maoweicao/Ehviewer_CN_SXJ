# E-Hentai 搜索语法说明

E-Hentai 的搜索系统基于 **NameSpace (命名空间) + Tags (标签)** 的设计。

## 命名空间前缀

| 前缀 | 命名空间 | 说明 |
|------|---------|------|
| `a:` | artist | 作者/画师 |
| `c:` | character | 角色 |
| `cos:` | cosplayer | Coser |
| `f:` | female | 女性标签 |
| `g:` | group | 团体/社团 |
| `l:` | language | 语言 |
| `m:` | male | 男性标签 |
| `x:` | mixed | 混合 |
| `o:` | other | 其他 |
| `p:` | parody | 原作/系列 |
| `r:` | reclass | 重新分类 |

---

## 1. 标签搜索 vs 标题搜索

- `f:milf` (等同于 `female:milf`) — 只搜索**标签**中带有 `female:milf` 的画廊
- `milf` — 同时搜索**标签和标题**中包含 `milf` 的画廊

> 搜索标题会多出标题中有 `milf` 但标签中没有的画廊

---

## 2. AND 逻辑（交集，默认）

搜索词以**空格**分隔表示交集（逗号不能用作分隔符）。

```
f:milf m:muscle
```

以上搜索同时拥有 `f:milf` 和 `m:muscle` 的画廊。

---

## 3. NOT 逻辑（排除）

`-` 号表示去除/排除。

```
pokemon -furry
```

搜索 pokemon，排除所有带 furry 标签/标题的画廊。

---

## 4. 多词标签

双引号 `""` 用于表示有多个单词的 tag。

```
f:"big breasts" f:"sex toys"
```

精确匹配 `big breasts` 和 `sex toys` 两个标签。

> 如果不加引号写成 `f:big breasts`，系统会当成 `f:big` 和 `breasts` 两个搜索条件。

---

## 5. 精确结尾匹配

`$` 号表示强制结尾。

```
c:sakura$
```

只匹配标签 `c:sakura`，不包含 `c:sakura kinomoto` 等变体。

```
f:big$
```

精确匹配 `big`，不会匹配 `big breasts` 等。

---

## 6. 通配符

- `*` 表示 0 个、1 个或多个任意字符
- `?` 和 `_` 表示任意单一字符

```
comic*xo*4
```

可匹配 `comicxo4` 或 `comicYYYYYYYxoKKKKKKK4`。

---

## 7. 搜索模式

本应用支持以下搜索模式：

- **普通搜索** — 同时搜索标签和标题
- **标签搜索** — 仅搜索指定标签
- **上传者搜索** — 搜索特定上传者的画廊
- **订阅搜索** — 搜索已订阅的画廊

---

## 8. 高级搜索选项

- 可限定搜索范围：画廊名称、标签、描述、种子文件名等
- 可设置最低评分和页数范围
- 可设置分类筛选（同人志、漫画、CG 等）

---

## 9. 标签芯片使用

- 输入关键字后，系统会自动推荐匹配的标签
- 点击推荐项可将其添加为**标签芯片**
- 标签芯片显示中文翻译名，搜索时使用英文原文
- 点击芯片上的 **×** 可移除该标签
- 自由文本可输入任意搜索词
- 搜索时，所有标签芯片将与自由文本合并
