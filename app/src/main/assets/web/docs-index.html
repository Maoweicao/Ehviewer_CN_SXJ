认证 (Auth)

▼
GET /api/v1/auth/status 获取认证状态

返回当前认证模式、是否已认证、是否局域网等信息。

POST /api/v1/auth/login 登录

使用密码或 Token 进行认证。

参数类型说明
passwordstring密码（password 模式）
tokenstringToken（token 模式）
POST /api/v1/auth/logout 登出

注销当前会话。

画廊 (Galleries)

▼
GET /api/v1/galleries 获取画廊列表

分页获取画廊列表，支持搜索和标签筛选。

参数类型必填说明
pageint否页码，默认1
limitint否每页数量，默认20
labelstring否标签筛选
searchstring否搜索关键词
GET /api/v1/galleries/{gid} 获取画廊详情

获取指定画廊的详细信息。

GET /api/v1/galleries/{gid}/thumbnail 获取缩略图

返回缩略图图片数据（JPEG）。

参数类型说明
maxWidthint最大宽度，默认300
maxHeightint最大高度，默认400
qualityint质量(1-100)，默认80
GET /api/v1/galleries/{gid}/pages 获取页面列表

返回画廊所有页面信息及下载状态。

GET /api/v1/galleries/{gid}/pages/{page} 获取页面图片

返回指定页面的图片数据。

参数类型说明
modestringlocal(默认)/proxy
DELETE /api/v1/galleries/{gid} 删除画廊

删除指定画廊。

标签 (Labels)

▼
GET /api/v1/labels 获取标签列表

获取所有下载标签及其画廊数量。

GET /api/v1/labels/{label}/galleries 获取标签下的画廊

获取指定标签下的画廊列表。

文件 (Files)

▼
GET /api/v1/folders 获取文件夹列表

获取 EhViewer 所有可用文件夹。

GET /api/v1/folders/{folder}/files 获取文件列表

分页获取指定文件夹中的文件。

参数类型说明
pageint页码，默认1
limitint每页数量，默认50
sortstringtime/name/size
orderstringasc/desc
searchstring搜索关键词

系统 (System)

▼
GET /api/v1/system/info 获取系统信息

返回设备信息、存储状态、应用版本等。

GET /api/v1/system/stats 获取系统统计

返回画廊下载状态统计。

推送 (Push)

▼
GET /api/v1/push/tasks 获取任务列表

获取所有推送任务列表。

设置 (Settings)

▼
GET /api/v1/settings/receive 获取接收设置

获取自动接收设置。

PUT /api/v1/settings/receive 更新接收设置

更新自动接收设置。

后台任务控制

创建 / 开始 / 暂停 / 继续 / 停止后台任务
GET /api/v1/background-tasks 获取后台任务列表

查询活跃与已完成的后台任务，支持 ?status=all|active|completed。

GET /api/v1/background-tasks/task-types 获取可创建的任务类型

返回可通过 POST /api/v1/background-tasks 创建的任务类型列表（TaskRegistry）。

POST /api/v1/background-tasks 创建后台任务

通过任务类名创建后台任务。

无参数任务：{"className": "com.hippo.ehviewer.task.CleanRedundancyTask"}

带参数任务：{"className": "...", "params": {"gids": [12345, 67890]}}

GET /api/v1/background-tasks/{taskId} 获取任务详情 / 日志

详情：GET /api/v1/background-tasks/{taskId}

日志：GET /api/v1/background-tasks/{taskId}/logs

POST /api/v1/background-tasks/{taskId}/start 开始 / 恢复任务

暂停的任务将被恢复；排队中的任务等待自动启动。

POST /api/v1/background-tasks/{taskId}/pause 暂停任务

仅支持实现了暂停逻辑的任务（isPausable=true）。

POST /api/v1/background-tasks/{taskId}/resume 继续任务

恢复已暂停的任务。

POST /api/v1/background-tasks/{taskId}/stop 停止任务

优雅停止后台任务（等同取消）。也支持 DELETE /api/v1/background-tasks/{taskId}。

POST /api/v1/tasks/{taskId}/pause 暂停传输任务

暂停传输任务（删除/归档/文件夹压缩）。配套 /resume、/stop 端点。
