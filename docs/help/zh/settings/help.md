## 常用搜索语法

E-Hentai 支持丰富的搜索语法，以下是一些常用示例:

| 语法 | 说明 | 示例 |
|------|------|------|
| `keyword` | 搜索关键词 | `fate grand order` |
| `"exact phrase"` | 精确匹配短语 | `"big breast"` |
| `keyword1 keyword2` | 同时包含多个关键词 (AND) | `ahegao swimsuit` |
| `keyword1 OR keyword2` | 包含任一关键词 (OR) | `elf OR orc` |
| `-keyword` | 排除关键词 | `fate -apocrypha` |
| `language:chinese` | 按语言筛选 | `language:chinese` |
| `uploader:name` | 按上传者筛选 | `uploader:sample` |
| `tag:namespace:value` | 按标签搜索 | `tag:character:saber` |
| `min_pages:N` | 最少页数 | `min_pages:50` |
| `max_pages:N` | 最多页数 | `max_pages:200` |

> 更多详细语法请在应用内点击"搜索语法说明"查看。
