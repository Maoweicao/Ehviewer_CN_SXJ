# 阅读设置

> 屏幕方向、阅读方向、页面缩放、翻页时间、翻页行为、屏幕显示、亮度等相关配置。

## 屏幕方向

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 屏幕旋转 | 阅读时的屏幕旋转方式 | `0` = 默认, `1` = 竖屏, `2` = 横屏, `3` = 传感器 | `0` (默认) |

> **推荐**: 传感器 (3) — 自动适应手持方向。

## 阅读方向

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 阅读方向 | 翻页方向 | `0` = 左到右, `1` = 右到左, `2` = 上到下 | `1` (右到左) |

> **推荐**: 右到左 (漫画标准阅读方向)。

## 页面缩放

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 页面缩放 | 图片的缩放适配方式 | `0` = 原始大小, `1` = 适应宽度, `2` = 适应高度, `3` = 适应屏幕, `4` = 固定比例 | `3` (适应屏幕) |

> **推荐**: 适应屏幕 (3) — 兼顾宽度和高度。

## 起始位置

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 起始位置 | 阅读时的初始滚动位置 | `0` = 左上, `1` = 右上, `2` = 左下, `3` = 右下, `4` = 中间 | `1` (右上) |

> **推荐**: 右上 (1) — 适合右到左漫画阅读。

## 翻页时间

> 注意: 存储值为十分之一秒 (如 5 = 0.5秒)。

| 名称 | 描述 | 范围 | 默认值 |
|------|------|------|--------|
| 快速翻页时间 | 快速翻页的间隔时间 | 1–10 (0.1–1.0秒) | 5 (0.5秒) |
| 静态图翻页时间 | 静态图片自动翻页间隔 | 10–1200 (1.0–120秒) | 40 (4.0秒) |
| 动图翻页时间 | 动态图片自动翻页间隔 | 10–1200 (1.0–120秒) | 80 (8.0秒) |

## 翻页行为

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 等待动画播放 | 自动翻页前等待GIF动画播放完毕 | true / false | true |
| 显示翻页倒计时 | 显示自动翻页的倒计时 | true / false | false |
| 禁用点击翻页 | 禁用点击屏幕翻页 | true / false | false |
| 禁用手势翻页 | 禁用滑动手势翻页 | true / false | false |

## 屏幕与显示

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 保持屏幕常亮 | 阅读时屏幕不自动息屏 | true / false | false |
| 显示时钟 | 阅读界面显示时钟 | true / false | true |
| 显示进度 | 阅读界面显示页码进度 | true / false | true |
| 显示电量 | 阅读界面显示电量信息 | true / false | true |
| 显示翻页间隔 | 显示翻页间隔时间 | true / false | true |

> **推荐**: 长时间阅读时开启保持屏幕常亮。

## 翻页与亮度

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 音量键翻页 | 使用音量键翻页 | true / false | false |
| 反向音量键 | 反转音量键翻页方向 (依赖音量键翻页) | true / false | false |
| 阅读全屏 | 阅读时隐藏系统导航栏 | true / false | true |
| 自定义屏幕亮度 | 使用应用内亮度调节 | true / false | false |
| 屏幕亮度 | 自定义屏幕亮度 (依赖自定义亮度) | 0–200% | 50% |

> **推荐**: 开启阅读全屏。亮度一般用系统调节即可。
