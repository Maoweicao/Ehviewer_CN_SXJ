# 下载设置

> 存储路径、速度控制、日志、更新策略、下载线程、图片质量、超时、排序与维护等相关配置。

## 存储

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 下载路径 | 设置下载文件的存储位置 | — | — |
| 媒体扫描 | 允许系统媒体扫描器扫描下载文件 | true / false | false |
| 重置媒体扫描 | 重新触发系统媒体扫描 | — | — |

> **推荐**: 媒体扫描关闭 — 隐藏下载内容不被相册等应用发现。

## 速度控制

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用最低下载速度 | 启用下载速度下限检测 | true / false | false |
| 最低下载速度 | 低于此速度将触发重连 (KB/s) | 64–1048576 | 64 |

## 日志

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用下载日志 | 记录下载过程的详细日志 | true / false | false |

> **推荐**: 调试时开启，日常使用关闭。

## 更新策略

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 增量更新 | 仅下载新增页面而非重新下载 | true / false | false |
| 显示文件夹时间 | 在下载卡片中显示文件夹创建时间 | true / false | false |
| 显示文件夹大小 | 在下载卡片中显示文件夹大小 | true / false | false |

## 下载线程

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 多线程下载 | 同时下载的图片线程数 | 1 / 3 / 5 / 7 | 3 |
| 预加载图片数 | 预加载的图片数量 | 3 / 5 / 7 / 11 / 13 / 17 | 5 |

> **推荐**: 多线程 3–5，预加载 5–7 (平衡速度与稳定性)。

## 下载列表

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 下载列表分页 | 下载列表使用分页显示 | true / false | true |

## 图片质量

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 图片分辨率 | 下载图片的分辨率 | `a` = 自动, `780`, `1280`, `1600`, `2400` | `a` (自动) |
| 下载原图 | 下载原始分辨率图片 (需要EX权限) | true / false | false |

> **推荐**: 自动 (默认) 即可。下载原图需EX账号权限。

## 超时

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用下载超时 | 启用下载超时检测 | true / false | false |
| 下载超时 | 下载超时时间 (秒) | 60–300 | 60 |

## 排序与网络

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 下载顺序升序 | 下载列表按升序排列 | true / false | true |
| 阅读时同步下载 | 阅读画廊时同步下载到本地 | true / false | false |
| 计量网络策略 | 使用计量网络(蜂窝数据)时的策略 | `0` = 暂停, `1` = 继续 | `0` (暂停) |

## 维护操作

| 名称 | 描述 |
|------|------|
| 恢复下载项 | 恢复中断的下载任务 |
| 清理冗余 | 清理冗余的下载文件 |
| 下载时合并 | 下载时自动合并同画廊 (默认关闭) |
| 合并重复画廊 | 合并已下载的重复画廊 |
| 扫描下载文件 | 扫描下载目录并更新记录 |
| 查看下载日志 | 查看下载日志记录 |
| 清除下载日志 | 清除所有下载日志 |
| 清理无效下载 | 清理无效的下载记录 |
| 修复已下载画廊 | 修复已下载的画廊数据 |
| 修复未知分类 | 修复分类未知的画廊 |
| 重建下载记录 | 重建下载数据库记录 |
