## 高级下载排序

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|

| 下载队列排序 | 下载队列的排序方式 | `0` = 默认, `1` = 少图优先, `2` = 多图优先, `3` = 类型优先级 | `0` (默认) |
| 画廊类型优先级 | 拖拽排序各类型的优先级 | — | — |
| 二级排序 | 主排序相同时的次排序方式 | `0` = 无, `1` = 少图优先, `2` = 多图优先 | `0` (无) |
