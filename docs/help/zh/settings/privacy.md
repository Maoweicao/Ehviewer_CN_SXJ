# 隐私设置

> 图案保护、安全模式、数据收集等隐私相关配置。

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 图案保护 | 设置图案锁保护应用 | — | — |
| 安全模式 | 启用安全模式 (隐藏应用内容) | true / false | false |
| 启用分析 | 允许收集匿名使用数据 | true / false | true |
| 关于分析 | 查看数据分析说明 | — | — |

> **推荐**:
> - 根据需要设置图案保护，保护个人隐私。
> - 安全模式在需要隐藏内容时开启。
> - 出于隐私考虑，建议关闭启用分析。
