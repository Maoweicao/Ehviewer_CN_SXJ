# 实验室

> 实验性功能：自动切换IP、AI浮层翻译、递进管理器等。

## 实验室主页

| 名称 | 描述 |
|------|------|
| 自动切换IP | 进入IP切换设置页面 |
| AI浮层翻译 | 进入AI翻译设置页面 |
| 递进管理器 | 管理递进式下载 |

## 自动切换IP

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用自动切换IP | 启用IP自动切换功能 | true / false | false |
| 订阅源管理 | 管理代理订阅源 | — | — |
| 单IP下载阈值 | 单个IP的最大下载次数 | 100 / 500 / 1000 / 无限制(0) | 50 |
| 风控解封时间 | IP被风控后的解封等待时间 | 240 / 360 / 720 / 1440 分钟 | 30 分钟 |
| 切换策略 | IP切换策略 | `0` = 轮询, `1` = 随机, `2` = 优先级, `3` = 最低延迟 | `0` (轮询) |
| 订阅刷新间隔 | 自动刷新订阅的时间间隔 | 30 / 60 / 120 / 360 / 720 / 1440 分钟 | 60 分钟 |
| 节点列表 | 查看可用IP节点 | — | — |
| IP池状态 | 查看IP池当前状态 | — | — |
| 清空IP池 | 清空所有已缓存的IP | — | — |

## AI 浮层翻译

### 基本设置

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用AI翻译 | 启用AI浮层翻译功能 | true / false | false |

### OCR 文字识别

| 名称 | 描述 |
|------|------|
| 局域网OCR服务器 | 配置PaddleOCR局域网服务器URL |
| 测试OCR连接 | 测试OCR服务器连接 |

### 翻译服务

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 翻译提供商 | 选择翻译服务提供商 | ollama / llamacpp / unsloth / deepseek / openai / custom | custom |
| API Key | 配置翻译服务的API密钥 | — | (空) |
| API URL | 配置翻译服务的API地址 | — | (空) |
| 模型选择 | 选择翻译模型 | — | gpt-4o-mini |
| 测试翻译 | 测试翻译服务是否正常 | — | — |

### 高级设置

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 自动图像探测 | 自动检测包含文字的图片区域 | true / false | true |
| 跳过动图页面 | 跳过GIF等动态图片的翻译 | true / false | true |

### 显示设置

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 浮层透明度 | 翻译浮层的透明度 | 100 / 150 / 180 / 200 / 220 / 240 | 180 |
| 字体大小 | 翻译文字的字体大小 (sp) | 10 / 12 / 14 / 16 / 18 / 20 / 24 | 14 |
| 显示位置 | 翻译浮层的显示位置 | `0` = 上方, `1` = 下方, `2` = 覆盖 | `0` (上方) |

### 缓存设置

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启用翻译缓存 | 缓存翻译结果避免重复请求 | true / false | true |
| 缓存过期 | 翻译缓存的过期时间 | 1 / 3 / 7 / 14 / 30 / 0(永不过期) 天 | 7 天 |
| 清除翻译缓存 | 清除所有已缓存的翻译结果 | — | — |
