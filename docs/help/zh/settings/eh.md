# EH 设置

> 画廊站点、主题、列表显示、历史记录、缩略图、画廊显示、过滤与评论等相关配置。

## 账号管理

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 退出登录 | 点击退出当前账号 | — | — |
| 身份Cookie | 查看/管理身份Cookie | — | — |

## 站点选择

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 画廊站点 | 选择画廊站点源 | `0` = e-hentai.org, `1` = exhentai.org | `1` (EX) |

> **推荐**: EX (exhentai.org) — 内容更完整。

## 网页配置

| 名称 | 描述 | 说明 |
|------|------|------|
| 网页配置 | 跳转到E-Hentai网页设置页面 | 在浏览器中打开UConfig |
| 我的标签 | 跳转到E-Hentai标签管理页面 | 在浏览器中管理标签 |

## 主题

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 主题 | 选择应用主题 | `0` = Light, `1` = Dark, `2` = Black | `0` (Light) |
| 自动切换主题 | 跟随系统暗色模式自动切换 | true / false | false |
| 应用导航栏主题色 | 导航栏使用主题色 | true / false | false |
| 系统主题 | 显示当前系统主题状态 | — | — |

> **推荐**: Dark 或 Black (护眼)，可开启自动切换主题跟随系统。

## 启动页

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 启动页面 | 设置启动时显示的页面 | `0` = 首页, `1` = 订阅, `2` = 热门 | `0` (首页) |

## 列表显示

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 列表模式 | 画廊列表的显示模式 | `0` = 详情, `1` = 缩略图 | `0` (详情) |
| 显示阅读进度 | 在列表中显示已读进度 | true / false | true |
| 详情大小 | 详情模式下的卡片大小 | `0` = 长, `1` = 短 | `0` (长) |
| 缩略图大小 | 缩略图模式下的图片大小 | `0` = 大, `1` = 中, `2` = 小 | `1` (中) |

> **推荐**: 详情模式 (默认) 信息最丰富。

## 历史记录

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 历史记录数量 | 最大保留的历史记录条数 | 100 / 500 / 1000 / 5000 / 10000 / 20000 | 100 |

> **推荐**: 1000 (平衡存储与查询需求)。

## 缩略图

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 手动缩略图分辨率 | 是否手动设置缩略图分辨率 | true / false | false |
| 自定义缩略图分辨率 | 手动设置缩略图分辨率 (px) | 100-500 | 250 |
| 修复缩略图URL | 修复缩略图加载失败问题 | true / false | false |

> **推荐**: 关闭手动分辨率 (自动即可)，如缩略图加载异常可开启修复URL。

## 画廊显示

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 显示日文标题 | 优先显示日文标题 | true / false | false |
| 显示画廊页数 | 在列表中显示画廊页数 | true / false | false |
| 显示加载速度 | 显示图片加载速度信息 | true / false | false |
| 显示标签翻译 | 显示标签的中文翻译 | true / false | true |
| 标签翻译来源 | 标签翻译数据源URL | — | Mapaler翻译库 |

> **推荐**: 开启显示画廊页数 (实用) 和显示标签翻译 (推荐)。

## 过滤与评论

| 名称 | 描述 | 可选值 | 默认值 |
|------|------|--------|--------|
| 过滤器 | 管理标题/上传者/标签过滤规则 | — | — |
| 显示画廊评论 | 显示画廊下方的评论区 | true / false | true |
| 启用评论评分过滤 | 按评分过滤评论 | true / false | false |
| 评论评分阈值 | 低于此评分的评论将被隐藏 | -100 ~ 100 | 0 |
| 显示画廊评分 | 显示画廊的星级评分 | true / false | true |
| 黑名单 | 管理黑名单 | — | — |

> **推荐**: 开启显示评论和评分，评论评分过滤按需开启。
