# EhViewer CN SXJ 使用帮助文档

<!-- screenshot: docs/help/zh/README-overview.png -->

## 概述

欢迎使用 **EhViewer CN SXJ** 帮助文档！本文档涵盖应用的所有主要功能和设置选项，帮助您快速上手并充分利用本应用。

**EhViewer CN SXJ** 是一款专为 Android 平台打造的 E-Hentai 浏览器，支持中文界面，提供画廊浏览、搜索、下载管理、收藏夹、浏览历史等丰富功能。
