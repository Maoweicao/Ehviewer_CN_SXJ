# 主界面

<!-- screenshot: help/zh/main-interface-overview.png -->

本文档介绍 EhViewer CN SXJ 的主界面结构，包括导航栏、搜索功能、画廊列表显示模式和排序选项。

---

## 1. 导航栏

应用采用**左侧抽屉式导航**，从屏幕左边缘右滑或点击左上角菜单按钮即可打开。

<!-- screenshot: help/zh/main-nav-drawer.png -->

### 1.1 导航菜单项

| 菜单项 | 图标 | 说明 |
|--------|------|------|
| 首页 | 🏠 | 主页画廊列表，显示最新内容 |
| 订阅 | 📬 | 查看已订阅的标签更新 |
| 热门 | 🔥 | 当前热门画廊 |
| 排行榜 | 🏆 | 画廊排行榜（按日/周/月/年） |
| 收藏 | ❤️ | 收藏夹管理 |
| 历史 | 🕐 | 浏览历史记录 |
| 下载 | ⬇️ | 下载管理 |
| 设置 | ⚙️ | 应用设置 |

### 1.2 导航栏附加功能

- **配额显示**：打开导航栏时自动加载并显示 EH 站点配额（每日浏览/搜索限额）
- **头像自定义**：点击导航头像可更换个人头像
- **壁纸自定义**：点击导航栏背景可更换壁纸，支持 GIF 动态壁纸
- **主题切换**：导航栏底部提供主题切换按钮，点击可在三种主题间循环切换

### 1.3 主题系统

| 主题 | 说明 |
|------|------|
| 浅色模式 | 白色背景，适合白天使用 |
| 深色模式 | 深色背景，适合夜间使用 |
| 纯黑模式 | AMOLED 纯黑背景，省电护眼 |

## 2. 搜索功能

### 2.1 搜索栏

<!-- screenshot: help/zh/main-search-bar.png -->

搜索栏位于界面顶部，具备以下功能：

- **搜索输入**：支持关键词、标签语法、上传者名称
- **搜索建议**：输入时自动显示标签数据库中的匹配建议
- **剪贴板检测**：自动检测剪贴板中的画廊 URL，弹出提示跳转

### 2.2 搜索模式

| 搜索模式 | 语法示例 | 说明 |
|----------|----------|------|
| 普通搜索 | `keyword` | 按关键词搜索标题和描述 |
| 标签搜索 | `language:chinese` | 按标签搜索 |
| 上传者搜索 | `uploader:xxx` | 按上传者名称搜索 |
| 以图搜图 | 📷 图片选择 | 上传图片进行相似度搜索 |
| 订阅搜索 | 切换到订阅模式 | 搜索已订阅的标签 |

### 2.3 搜索面板

点击搜索栏右侧展开按钮，打开完整搜索面板：

#### 分类筛选

支持 11 种 E-Hentai 分类的复选框筛选：

| 分类 | 说明 |
|------|------|
| Doujinshi | 同人志 |
| Manga | 漫画 |
| Artist CG | 画师CG |
| Game CG | 游戏CG |
| Western | 西方 |
| Non-H | 非H |
| Image Set | 图集 |
| Cosplay | Cosplay |
| Asian | 亚洲 |
| Misc | 杂项 |
| Unknown | 未知 |

#### 高级搜索

<!-- screenshot: help/zh/main-advanced-search.png -->

展开高级搜索面板可设置更多筛选条件：

- **搜索名称**（SNAME）：仅搜索画廊标题
- **搜索标签**（STAGS）：仅搜索标签
- **最低评分**：设置最低评分过滤
- **日期范围**：按年/月/周/日筛选

### 2.4 以图搜图

<!-- screenshot: help/zh/main-image-search.png -->

切换到以图搜图模式后：

1. 选择本地图片或拍照
2. 可开启**相似度扫描**提高准确度
3. 系统返回相似画廊结果

## 3. 画廊列表

### 3.1 列表显示模式

<!-- screenshot: help/zh/main-gallery-list.png -->

画廊列表采用**瀑布流布局**，每个卡片显示以下信息：

| 元素 | 说明 |
|------|------|
| 缩略图 | 画廊封面图片 |
| 标题 | 画廊标题（支持多语言标题） |
| 上传者 | 上传者名称 |
| 评分 | 星级评分指示器 |
| 分类标签 | 彩色分类标签（如 Doujinshi、Manga 等） |
| 发布时间 | 画廊发布日期 |
| 语言 | 语言标记 |

### 3.2 列表交互

| 操作 | 说明 |
|------|------|
| 点击卡片 | 进入画廊详情页 |
| 长按卡片 | 弹出快捷操作菜单 |
| 下拉刷新 | 刷新当前列表 |
| 快速滚动 | 使用 FastScroller 快速跳转 |
| 长按 FAB | 进入多选模式 |

### 3.3 FAB 浮动按钮

<!-- screenshot: help/zh/main-fab.png -->

界面右下角的浮动按钮（FAB）提供快捷操作：

- **单击**：展开子菜单（收藏、下载等）
- **长按**：进入多选模式，可批量选择画廊进行下载或收藏
- **自动隐藏**：向下滚动时自动隐藏，向上滚动时显示

## 4. 右侧抽屉

从屏幕右边缘左滑可打开右侧抽屉，内容随当前页面变化：

| 页面 | 右侧抽屉内容 |
|------|-------------|
| 画廊列表 | 书签管理（快速搜索）/ 订阅管理 |
| 收藏页 | 收藏夹选择器（10 个云端 + 1 个本地） |
| 下载页 | 下载标签列表 |

## 5. 画廊详情页

<!-- screenshot: help/zh/main-gallery-detail.png -->

### 5.1 页面结构

从列表点击画廊卡片进入详情页，包含以下区域：

| 区域 | 内容 |
|------|------|
| 头部 | 分类颜色背景、缩略图、标题、上传者 |
| 信息 | 语言、页数、文件大小、发布时间、收藏次数 |
| 操作 | 评分星级、下载按钮、阅读按钮 |
| 标签 | 画廊标签列表（可点击搜索） |
| 评论 | 用户评论列表 |
| 预览 | 页面缩略图网格 |

### 5.2 交互功能

| 操作 | 说明 |
|------|------|
| 点击标题 | 复制标题到剪贴板 |
| 点击上传者 | 搜索该上传者的所有画廊 |
| 长按上传者 | 复制上传者名称 |
| 点击分类标签 | 按该分类筛选 |
| 点击下载按钮 | 开始下载 |
| 长按下载按钮 | 显示下载选项（选择分类） |
| 点击阅读按钮 | 进入阅读器 |

## 6. URL 跳转

应用支持自动识别并跳转以下类型的 E-Hentai URL：

| URL 类型 | 示例 |
|----------|------|
| 画廊详情页 | `https://e-hentai.org/g/{gid}/{token}/` |
| 画廊列表页 | 搜索 URL |
| 画廊页面 | `https://e-hentai.org/s/{token}/{gid}-{page}` |

> 💡 复制画廊链接后打开应用，会自动弹出跳转提示。
