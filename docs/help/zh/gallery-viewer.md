# 画廊阅读器

<!-- screenshot: help/zh/viewer-overview.png -->

本文档介绍 EhViewer CN SXJ 的画廊阅读器功能，包括翻页模式、缩放设置、自动翻页和阅读器菜单选项。

---

## 1. 进入阅读器

从画廊详情页点击**阅读**按钮进入阅读器。阅读器支持三种数据来源：

| 数据来源 | 说明 |
|----------|------|
| 在线画廊 | 从 E-Hentai 站点加载（需网络） |
| 本地文件夹 | 读取本地图片文件夹 |
| 压缩包 | 读取 ZIP/CBR 压缩包中的图片 |

---

## 2. 阅读方向

<!-- screenshot: help/zh/viewer-layout-mode.png -->

阅读器支持三种翻页方向：

| 方向 | 说明 | 适用场景 |
|------|------|----------|
| 右 → 左 | 从右向左翻页（**默认**） | 日本漫画阅读习惯 |
| 左 → 右 | 从左向右翻页 | 西方漫画、画集 |
| 上 → 下 | 从上向下滚动 | 条漫、长图 |

### 切换方式

点击屏幕中央区域弹出设置对话框，在**阅读方向**下拉菜单中选择。

---

## 3. 缩放模式

<!-- screenshot: help/zh/viewer-scale-mode.png -->

| 缩放模式 | 说明 |
|----------|------|
| 原始尺寸 | 以图片原始分辨率显示 |
| 适应屏幕 | 自动缩放使图片完整显示在屏幕内 |
| 适应宽度 | 图片宽度铺满屏幕（默认推荐） |
| 适应高度 | 图片高度铺满屏幕 |

> 💡 阅读时可双指捏合/张开进行手动缩放，双击屏幕可快速切换缩放模式。

---

## 4. 翻页方式

阅读器支持多种翻页方式，可根据个人习惯选择：

### 4.1 手势滑动

- 左右或上下滑动翻页
- 滑动方向与阅读方向一致

### 4.2 点击翻页

- 点击屏幕左/右侧边缘区域翻页
- 可在设置中禁用

### 4.3 音量键翻页

- 按音量 + / - 键翻页
- 可在设置中启用/禁用
- 支持反转音量键方向

### 4.4 键盘翻页

- Page Up / Page Down 翻页
- 方向键翻页
- 适用于外接键盘场景

### 4.5 鼠标滚轮

- 滚轮翻页
- 支持方向反转
- 适用于外接鼠标场景

---

## 5. 自动翻页

<!-- screenshot: help/zh/viewer-auto-page.png -->

### 5.1 开启方式

点击底部控制面板的**播放按钮**开启自动翻页。

### 5.2 翻页时间设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 静态图片翻页时间 | 4 秒 | 普通图片自动翻页间隔 |
| 动态图片翻页时间 | 8 秒 | GIF/APNG 动图翻页间隔 |
| 快速阅读模式 | 0.1-1.0 秒 | 快速翻页时间，步进 0.5 秒 |

### 5.3 高级选项

- **等待动画完成**：开启后，当前页加载或动画播放完毕才翻到下一页
- **倒计时显示**：可选显示翻页倒计时（最后 15 秒）

---

## 6. 阅读器菜单

<!-- screenshot: help/zh/viewer-menu.png -->

点击屏幕中央区域弹出设置对话框，包含以下设置项：

### 6.1 显示设置

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 屏幕旋转 | 下拉选择 | 自动 / 竖屏 / 横屏 / 传感器 |
| 阅读方向 | 下拉选择 | 左→右 / 右→左 / 上→下 |
| 页面缩放 | 下拉选择 | 原始 / 适应 / 适应宽度 / 适应高度 |
| 起始位置 | 下拉选择 | 左上 / 右上 / 左下 / 右下 |

### 6.2 自动翻页设置

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 快速翻页时间 | 数值 (0.1-1.0s) | 步进 0.5 秒 |
| 静态图片翻页时间 | 数值 (秒) | 自动翻页间隔 |
| 动态图片翻页时间 | 数值 (秒) | GIF/APNG 翻页间隔 |
| 等待动画完成 | 开关 | 等待加载完成再翻页 |
| 显示翻页倒计时 | 开关 | 显示倒计时 |

### 6.3 交互设置

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 禁用点击翻页 | 开关 | 禁用点击屏幕边缘翻页 |
| 禁用手势翻页 | 开关 | 禁用手势滑动翻页 |
| 音量键翻页 | 开关 | 音量键控制翻页 |
| 反转音量键 | 开关 | 反转音量键方向 |

### 6.4 界面设置

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 保持屏幕常亮 | 开关 | 阅读时屏幕不熄灭 |
| 显示时钟 | 开关 | 顶部状态栏显示时钟 |
| 显示进度 | 开关 | 显示页码进度文字 |
| 显示电量 | 开关 | 显示电量指示器 |
| 显示翻页间隔 | 开关 | 显示页间分隔线 |
| 全屏阅读 | 开关 | 隐藏系统 UI |
| 自定义屏幕亮度 | 开关 + 滑块 | 0-200 亮度调节 |

## 7. 底部控制面板

<!-- screenshot: help/zh/viewer-bottom-panel.png -->

阅读器底部提供控制面板：

| 控件 | 说明 |
|------|------|
| 进度条 (SeekBar) | 拖动快速跳页，显示当前页/总页数 |
| 自动翻页按钮 | 播放/暂停自动翻页 |
| 底部指示器 | 点击展开控制面板 |

---

## 8. 顶部标题栏

| 控件 | 说明 |
|------|------|
| 返回按钮 | 返回画廊详情页 |
| 标题 | 显示当前画廊标题 |
| 菜单按钮 | 打开阅读器设置 |

---

## 9. 长按操作

<!-- screenshot: help/zh/viewer-long-press.png -->

长按当前页面弹出操作对话框：

| 操作 | 说明 |
|------|------|
| 分享图片 | 将当前页图片分享到其他应用 |
| 保存图片 | 保存到本地相册 |
| 另存为 | 选择保存位置 |
| AI 翻译 | （实验功能）自动翻译图片中的文字 |

---

## 10. 画中画模式

<!-- screenshot: help/zh/viewer-pip.png -->

支持画中画（PiP）小窗模式：

- 显示缩略图、标题、阅读进度
- 提供上一页/下一页/首页/播放按钮
- 可一键恢复全屏阅读

---

## 11. AI 翻译（实验功能）

<!-- screenshot: help/zh/viewer-ai-translate.png -->

通过 AI 翻译功能可自动翻译画廊图片中的文字：

1. 长按当前页面，选择 **AI 翻译**
2. 系统自动识别图片中的文字并翻译
3. 翻译结果叠加显示在原图上方
4. 可设置跳过动态图片（GIF/APNG）

> ⚠️ 此功能为实验性功能，翻译质量可能不稳定，且会消耗额外的网络流量。
