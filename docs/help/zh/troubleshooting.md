# 常见问题与解决方案

<!-- screenshot: help/zh/troubleshooting-overview.png -->

本文档汇总了 EhViewer CN SXJ 使用过程中的常见问题及其解决方案。

---

## 1. 网络与连接问题

### 1.1 无法加载画廊列表

**症状**：首页显示空白或加载失败。

**解决方案**：

| 方案 | 操作 |
|------|------|
| 检查网络 | 确认设备已连接网络，尝试切换 Wi-Fi / 移动数据 |
| 检查代理 | 在设置中确认代理配置正确 |
| 检查 Hosts | 确认 Hosts 文件未被修改导致域名解析异常 |
| 清除缓存 | 进入设置 → 高级 → 清除缓存 |
| 更换 DNS | 尝试使用公共 DNS（如 8.8.8.8 或 1.1.1.1） |

### 1.2 无法登录 E-Hentai

**症状**：输入账号密码后提示登录失败。

**解决方案**：

1. 确认账号密码正确（区分大小写）
2. 检查是否需要验证码
3. 尝试在浏览器中登录 E-Hentai 确认账号状态
4. 如果账号被封禁，需要联系 E-Hentai 站长

### 1.3 ExHentai 无法访问

**症状**：选择 ExHentai 后无法加载内容。

**解决方案**：

- ExHentai 需要 E-Hentai 账号有一定注册时长
- 确认账号有 ExHentai 访问权限
- 检查网络环境是否屏蔽了 ExHentai 域名

## 2. 下载问题

### 2.1 下载速度慢

**症状**：下载进度长时间不更新或速度极慢。

**解决方案**：

| 方案 | 操作 |
|------|------|
| 检查网络 | 确认网络连接稳定 |
| 调整并发数 | 进入设置 → 下载 → 调整同时下载数量 |
| 检查存储空间 | 确认设备存储空间充足 |
| 重试下载 | 长按失败任务，选择重试 |

### 2.2 下载失败

**症状**：下载任务显示失败状态。

**解决方案**：

1. 检查网络连接
2. 确认存储空间充足
3. 尝试清除下载缓存后重新下载
4. 检查下载目录是否有写入权限

### 2.3 下载目录找不到

**症状**：不知道下载的文件保存在哪里。

**解决方案**：

- 进入设置 → 下载 → 下载目录，查看当前设置的保存路径
- 默认路径通常为 `/sdcard/Download/EhViewer/`
- 可在设置中自定义下载目录

## 3. 阅读器问题

### 3.1 图片加载缓慢

**症状**：阅读器中图片长时间显示加载中。

**解决方案**：

| 方案 | 操作 |
|------|------|
| 检查网络 | 确认网络连接正常 |
| 清除图片缓存 | 设置 → 高级 → 清除图片缓存 |
| 降低画质 | 设置 → 阅读 → 降低图片加载画质 |
| 使用下载阅读 | 先下载画廊再阅读，避免在线加载 |

### 3.2 翻页不流畅

**症状**：翻页时出现卡顿或延迟。

**解决方案**：

1. 关闭不需要的显示元素（时钟、电量、进度等）
2. 降低图片画质设置
3. 确认设备性能满足要求
4. 关闭自动翻页的等待动画选项

### 3.3 翻页方向不对

**症状**：翻页方向与预期不符。

**解决方案**：

- 点击屏幕中央打开设置对话框
- 在**阅读方向**中选择正确的翻页方向
- 右→左适合日本漫画，左→右适合西方漫画，上→下适合条漫

## 4. 收藏夹问题

### 4.1 云端收藏不同步

**症状**：在其他设备上看不到已收藏的画廊。

**解决方案**：

1. 确认使用同一 E-Hentai 账号登录
2. 确认收藏到了**云端收藏夹**而非本地收藏夹
3. 下拉刷新收藏列表

### 4.2 本地收藏丢失

**症状**：更新应用后本地收藏消失。

**解决方案**：

- 卸载重装前务必备份本地数据
- 使用应用内置的备份功能（设置 → 高级 → 备份）
- 本地收藏存储在应用私有数据中，清除数据会丢失

## 5. 界面与显示问题

### 5.1 应用闪退

**症状**：打开应用或操作时突然退出。

**解决方案**：

| 方案 | 操作 |
|------|------|
| 更新应用 | 确认使用最新版本 |
| 清除缓存 | 设置 → 高级 → 清除缓存 |
| 重启设备 | 重启手机后再试 |
| 清除数据 | 设置 → 应用 → EhViewer → 清除数据（注意备份） |
| 检查内存 | 确认设备可用内存充足 |

### 5.2 界面显示异常

**症状**：界面元素错位、文字截断等。

**解决方案**：

1. 尝试切换主题
2. 检查系统字体大小设置
3. 清除应用缓存
4. 确认使用最新版本

### 5.3 缩略图不显示

**症状**：画廊列表中缩略图为空白。

**解决方案**：

- 检查网络连接
- 清除图片缓存后刷新
- 确认存储空间充足（缩略图缓存需要空间）

## 6. 账号与隐私问题

### 6.1 忘记安全锁密码

**症状**：设置了应用锁但忘记密码。

**解决方案**：

- 清除应用数据可以重置安全锁（会丢失所有本地数据）
- 建议设置密码时记录在安全的地方

### 6.2 如何切换账号

**解决方案**：

1. 进入设置 → E-Hentai → 退出登录
2. 重新启动应用
3. 使用新账号登录

### 6.3 如何清除浏览数据

**解决方案**：

进入设置 → 隐私，可分别清除：

- 浏览历史
- 搜索历史
- 图片缓存
- Cookie

## 7. 性能问题

### 7.1 应用占用空间过大

**症状**：应用数据占用大量存储空间。

**解决方案**：

| 操作 | 说明 |
|------|------|
| 清除图片缓存 | 设置 → 高级 → 清除图片缓存 |
| 清除下载 | 删除不需要的下载内容 |
| 移动下载目录 | 将下载目录设置到 SD 卡 |
| 定期清理 | 定期清理历史记录和缓存 |

### 7.2 应用耗电过多

**症状**：应用在后台消耗大量电量。

**解决方案**：

1. 关闭后台下载（设置 → 下载）
2. 减少自动刷新频率
3. 使用纯黑主题（AMOLED 屏幕省电）
4. 阅读时开启屏幕常亮仅在需要时使用
