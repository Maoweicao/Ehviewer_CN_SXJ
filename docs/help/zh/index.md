# EhViewer CN SXJ 快速入门

<!-- screenshot: help/zh/index-overview.png -->

## 简介

**EhViewer CN SXJ** 是一款专为 Android 平台打造的 E-Hentai 画廊浏览器，支持完整中文界面。它提供了流畅的画廊浏览体验、强大的搜索功能、便捷的下载管理、灵活的收藏夹以及完整的浏览历史记录。

### 主要特性

- 🎨 **三种主题**：浅色、深色、纯黑，适应不同使用场景
- 🔍 **多种搜索**：关键词、标签、上传者、以图搜图
- 📥 **下载管理**：标签分类、批量下载、拖拽排序
- ❤️ **收藏夹**：10 个云端收藏夹 + 1 个本地收藏夹
- 📖 **阅读器**：三种翻页方向、四种缩放模式、自动翻页
- 🌐 **双站点支持**：E-Hentai / ExHentai
- 🤖 **AI 翻译**：实验功能，自动翻译图片中的文字

## 安装与首次启动

### 系统要求

- Android 5.0 (API 21) 及以上
- 建议 2GB 以上可用内存
- 需要网络权限和存储权限

### 首次启动流程

<!-- screenshot: help/zh/index-first-launch.png -->

首次启动应用时，会依次经历以下步骤：

| 步骤 | 说明 |
|------|------|
| 1. 安全锁设置 | 可选设置应用锁，保护隐私 |
| 2. 使用警告 | 阅读并确认使用须知 |
| 3. 分析同意 | 选择是否允许匿名使用数据收集 |
| 4. 账号登录 | 输入 E-Hentai 账号和密码 |
| 5. 站点选择 | 选择 E-Hentai 或 ExHentai |
| 6. 进入首页 | 开始浏览画廊 |

> 💡 如果没有 E-Hentai 账号，需要先在 [E-Hentai 官网](https://e-hentai.org) 注册。

## 快速上手

### 浏览画廊

1. 启动应用后默认进入**首页**，显示最新画廊列表
2. 点击画廊卡片进入**详情页**，查看标题、标签、评分等信息
3. 点击**阅读**按钮开始阅读

### 搜索画廊

1. 点击顶部搜索栏
2. 输入关键词或标签（如 `artist:xxx`、`language:chinese`）
3. 可展开高级搜索面板，按分类、评分等条件筛选

### 下载画廊

1. 在画廊详情页点击**下载**按钮
2. 或在列表页长按 FAB 进入多选模式，批量下载
3. 在左侧导航栏选择**下载**查看下载进度

### 收藏画廊

1. 在画廊详情页点击**收藏**按钮
2. 选择目标收藏夹（10 个云端 + 1 个本地）
3. 在左侧导航栏选择**收藏**管理已收藏内容
