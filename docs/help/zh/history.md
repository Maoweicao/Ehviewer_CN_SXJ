# 浏览历史

<!-- screenshot: help/zh/history-overview.png -->

本文档介绍 EhViewer CN SXJ 的浏览历史记录功能。

---

## 1. 进入历史记录

通过左侧导航栏点击**历史**进入浏览历史页面。

---

## 2. 界面结构

<!-- screenshot: help/zh/history-interface.png -->

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 显示"历史记录"标题，带返回按钮和菜单按钮 |
| 历史列表 | 瀑布流布局显示浏览过的画廊 |
| 空状态 | 无历史记录时显示大图标和提示文字 |

---

## 3. 列表项内容

<!-- screenshot: help/zh/history-item.png -->

每个历史记录项显示以下信息：

| 元素 | 说明 |
|------|------|
| 缩略图 | 画廊封面图片 |
| 标题 | 画廊标题 |
| 上传者 | 上传者名称 |
| 评分 | 星级评分指示器 |
| 分类标签 | 带分类颜色背景的标签（如 Doujinshi、Manga 等） |
| 发布时间 | 画廊发布日期 |
| 语言 | 语言标记 |

---

## 4. 交互操作

### 4.1 点击

点击历史记录项进入画廊详情页，支持缩略图转场动画。

### 4.2 长按

<!-- screenshot: help/zh/history-long-press.png -->

长按弹出快捷操作菜单：

| 操作 | 说明 |
|------|------|
| 下载 | 将该画廊加入下载队列 |
| 添加到收藏 | 将该画廊收藏到指定收藏夹 |

### 4.3 左滑删除

<!-- screenshot: help/zh/history-swipe-delete.png -->

在历史记录项上**向左滑动**可删除单条记录：

- 滑动后显示删除确认
- 支持滑动删除动画（SwipeDismissItemAnimator）
- 删除后不可撤销

---

## 5. 清除全部历史

<!-- screenshot: help/zh/history-clear-all.png -->

通过工具栏菜单可清除所有浏览历史：

1. 点击工具栏右上角的**菜单按钮**
2. 选择**清除全部**
3. 弹出确认对话框
4. 确认后删除所有历史记录

> ⚠️ 清除全部历史记录后不可恢复，请谨慎操作。

---

## 6. 快速滚动

历史记录列表支持 FastScroller 快速滚动功能，当历史记录较多时，可拖动右侧滚动条快速跳转到目标位置。

---

## 7. 技术说明

- 使用 GreenDAO 数据库懒加载历史记录，支持大量数据的流畅浏览
- 支持共享元素转场动画，从列表到详情页的视觉过渡更自然
- 历史记录按浏览时间倒序排列（最新浏览的在前）
