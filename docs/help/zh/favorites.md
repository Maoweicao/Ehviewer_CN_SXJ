# 收藏夹

<!-- screenshot: help/zh/favorites-overview.png -->

本文档介绍 EhViewer CN SXJ 的收藏夹管理功能，包括云端收藏夹和本地收藏夹的使用方法。

---

## 1. 进入收藏夹

通过左侧导航栏点击**收藏**进入收藏夹管理页面。

---

## 2. 收藏夹类型

<!-- screenshot: help/zh/favorites-types.png -->

EhViewer 提供两种类型的收藏夹：

### 2.1 云端收藏夹

| 编号 | 说明 |
|------|------|
| 收藏夹 0 - 收藏夹 9 | 共 10 个云端收藏夹，可自定义命名 |
| 全部云端 | 显示所有云端收藏夹中的内容 |

云端收藏夹与 E-Hentai 账号绑定，在不同设备间同步。

### 2.2 本地收藏夹

| 类型 | 说明 |
|------|------|
| 本地收藏夹 | 存储在设备本地，不与账号同步 |

本地收藏夹适合收藏不便公开或私密的内容，仅保存在当前设备。

---

## 3. 界面结构

<!-- screenshot: help/zh/favorites-interface.png -->

| 区域 | 说明 |
|------|------|
| 顶部搜索栏 | 显示当前收藏夹名称，可输入关键词搜索 |
| 右侧抽屉 | 收藏夹选择器，切换不同收藏夹 |
| 画廊列表 | 显示当前收藏夹中的画廊，支持多种布局模式 |
| FAB 浮动按钮 | 收藏快捷操作 |

---

## 4. 收藏夹选择器

<!-- screenshot: help/zh/favorites-drawer.png -->

从屏幕右边缘左滑打开右侧抽屉，显示收藏夹选择器：

### 4.1 收藏夹列表

| 收藏夹 | 说明 |
|--------|------|
| 全部云端 | 显示所有云端收藏 |
| 收藏夹 0 - 9 | 各云端收藏夹（带数量显示） |
| 本地收藏夹 | 本地存储的收藏 |

每个收藏夹右侧显示该收藏夹中的画廊数量。

### 4.2 默认收藏夹

通过抽屉底部菜单可设置默认收藏夹：

| 选项 | 说明 |
|------|------|
| 让我选择 | 每次收藏时弹出选择对话框 |
| 本地收藏夹 | 默认收藏到本地 |
| 收藏夹 0 - 9 | 默认收藏到指定云端收藏夹 |

---

## 5. 收藏画廊

### 5.1 从画廊详情页收藏

1. 在画廊详情页点击**收藏**按钮
2. 如已设置默认收藏夹，直接收藏到该收藏夹
3. 如未设置默认收藏夹，弹出选择对话框

### 5.2 从列表页收藏

1. 在画廊列表页展开 FAB 子菜单
2. 点击**添加到收藏夹**按钮
3. 选择目标收藏夹

---

## 6. 搜索收藏内容

<!-- screenshot: help/zh/favorites-search.png -->

在收藏夹页面顶部搜索栏输入关键词，可在当前收藏夹内搜索：

- 搜索结果仅限当前选中的收藏夹
- 搜索栏标题格式：`收藏夹名 — 关键词`
- 提示文字：`搜索 收藏夹名`

---

## 7. 列表操作

### 7.1 单项操作

| 操作 | 说明 |
|------|------|
| 点击 | 进入画廊详情页 |
| 长按 | 弹出操作菜单 |

### 7.2 多选操作

<!-- screenshot: help/zh/favorites-multi-select.png -->

长按 FAB 进入多选模式：

| 操作 | 说明 |
|------|------|
| 批量移动 | 将选中画廊移动到其他收藏夹 |
| 批量删除 | 从当前收藏夹中移除选中画廊 |
| 批量下载 | 下载选中画廊 |

---

## 8. FAB 操作

<!-- screenshot: help/zh/favorites-fab.png -->

展开 FAB 子菜单提供以下快捷操作：

| 按钮 | 说明 |
|------|------|
| 添加到收藏夹 | 收藏当前画廊 |
| 移动到其他收藏夹 | 在收藏夹之间移动 |
| 从收藏夹移除 | 取消收藏 |

---

## 9. 新手引导

首次进入收藏夹页面时，会显示新手引导（ShowcaseView），提示用户从右侧抽屉打开收藏夹选择器来管理收藏夹。
