# 下载管理

<!-- screenshot: help/zh/download-overview.png -->

本文档介绍 EhViewer CN SXJ 的下载管理功能，包括下载界面、标签系统、筛选排序和高级操作。

---

## 1. 进入下载管理

通过左侧导航栏点击**下载**进入下载管理页面。

---

## 2. 界面结构

<!-- screenshot: help/zh/download-interface.png -->

下载管理页面由以下部分组成：

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 显示当前标签名和下载数量 |
| 标签抽屉 | 左侧抽屉显示下载标签列表 |
| 分类筛选 | 下拉选择器，按 E-Hentai 分类筛选 |
| 下载列表 | 瀑布流布局，显示下载任务 |
| 分页指示器 | 底部显示页码导航 |
| 搜索栏 | 搜索已下载内容 |

---

## 3. 标签系统

<!-- screenshot: help/zh/download-labels.png -->

下载管理支持自定义标签分类，方便组织大量下载内容：

### 3.1 标签抽屉

从左侧边缘右滑打开标签抽屉（DownloadLabelDraw），显示所有自定义标签及每个标签下的下载数量。

### 3.2 默认标签

- **全部**：显示所有下载项
- **未分类**：未分配标签的下载项

### 3.3 自定义标签

- 长按标签可编辑或删除
- 可创建新标签对下载进行分类管理

---

## 4. 筛选功能

### 4.1 按状态筛选

<!-- screenshot: help/zh/download-filter-status.png -->

| 状态 | 说明 |
|------|------|
| 全部 | 显示所有状态的下载 |
| 已完成 | 下载完成的任务 |
| 未开始 | 尚未开始的下载 |
| 等待中 | 排队等待下载的任务 |

| 失败 | 下载失败的任务 |

### 4.2 按分类筛选

| 分类 | 说明 |

| 杂项 | Misc |
| 同人志 | Doujinshi |
| 漫画 | Manga |
| 画师CG | Artist CG |
| 游戏CG | Game CG |
| 图集 | Image Set |
| Cosplay | Cosplay |
| 亚洲 | Asian |
| 非H | Non-H |
| 西方 | Western |
| 未知 | Unknown |

## 5. 排序选项

<!-- screenshot: help/zh/download-sort.png -->

通过工具栏菜单访问排序选项：

| 排序方式 | 说明 |
|----------|------|
| 默认排序 | 按添加顺序排列 |
| 画廊 ID 升序/降序 | 按 GID 排序 |
| 创建时间 升序/降序 | 按添加到下载列表的时间排序 |
| 评分 升序/降序 | 按画廊评分排序 |
| 名称 升序/降序 | 按标题字母顺序排序 |
| 文件大小 升序/降序 | 按下载文件大小排序 |

---

## 6. 列表项操作

<!-- screenshot: help/zh/download-item-actions.png -->

### 6.1 点击操作

- **点击**：进入画廊详情页，或继续上次的阅读进度

### 6.2 长按菜单

长按下载项弹出操作菜单，显示缩略图预览和标签 Chips：

| 操作 | 说明 |
|------|------|
| 查看详情 | 进入画廊详情页 |
| 继续阅读 | 从上次位置继续阅读 |
| 删除 | 从下载列表中移除 |
| 更多操作 | 分享、复制链接等 |

### 6.3 拖拽排序

长按下载项后可拖拽调整下载顺序（DragDropManager）。

---

## 7. 工具栏菜单

<!-- screenshot: help/zh/download-toolbar.png -->

工具栏提供以下快捷功能：

| 菜单项 | 说明 |
|--------|------|
| 排序/筛选 | 打开筛选和排序子菜单 |
| 全部开始 | 启动所有暂停/等待的下载任务 |
| 全部暂停 | 暂停所有正在下载的任务 |
| 重置阅读进度 | 清除所有下载项的阅读进度记录 |
| 搜索下载画廊 | 在下载列表中搜索 |
| 导入本地压缩包 | 导入 ZIP/CBR 文件 |

---

## 8. FAB 操作

<!-- screenshot: help/zh/download-fab.png -->

- **单击 FAB**：展开搜索和筛选快捷按钮
- **长按 FAB**：进入多选模式，可批量操作多个下载任务

---

## 9. 分页控制

当下载数量较多时，自动启用分页功能：

| 设置 | 可选值 |
|------|--------|
| 每页数量 | 50 / 100 / 200 / 300 / 500 条 |

分页指示器位于页面底部，可点击页码快速跳转。

---

## 10. 高级功能

### 10.1 进度追踪

- 下载进度实时显示
- 使用 SpiderInfo 追踪每个画廊的下载进度
- 断点续传支持

### 10.2 压缩导出

- 可选择多个画廊进行压缩导出
- 支持将画廊打包为压缩文件

### 10.3 未读标记

- 新下载或有更新的内容显示未读标记
- 支持显示未读下载数量

### 10.4 导入本地文件

- 支持导入本地 ZIP/CBR 压缩包
- 导入后可在阅读器中打开

---

## 11. 搜索已下载内容

<!-- screenshot: help/zh/download-search.png -->

点击工具栏搜索图标打开搜索栏，可在下载列表中按标题或关键词搜索已下载的画廊。
