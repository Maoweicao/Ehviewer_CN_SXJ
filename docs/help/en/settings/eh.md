# EH Settings

> Gallery site, theme, list display, history, thumbnails, gallery display, filters, and comments.

## Account Management

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Sign out | Sign out of the current account | — | — |
| Identity cookies | View/manage identity cookies | — | — |

## Site Selection

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Gallery site | Choose the gallery source site | `0` = e-hentai.org, `1` = exhentai.org | `1` (EX) |

> **Recommended**: EX (exhentai.org) — more complete content.

## Web Configuration

| Name | Description | Notes |
|------|-------------|-------|
| UConfig | Open E-Hentai web settings page | Opens in browser |
| My Tags | Open E-Hentai tag management page | Manage tags in browser |

## Theme

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Theme | Select the app theme | `0` = Light, `1` = Dark, `2` = Black | `0` (Light) |
| Auto theme switch | Follow system dark mode automatically | true / false | false |
| Apply nav bar theme color | Apply theme color to the navigation bar | true / false | false |
| System theme | Display current system theme status | — | — |

> **Recommended**: Dark or Black (easier on the eyes). Enable auto theme switch to follow system settings.

## Launch Page

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Launch page | Page shown on app startup | `0` = Home, `1` = Subscription, `2` = Popular | `0` (Home) |

## List Display

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| List mode | How galleries are displayed in the list | `0` = Detail, `1` = Thumbnail | `0` (Detail) |
| Show read progress | Show reading progress in the gallery list | true / false | true |
| Detail size | Card size in detail mode | `0` = Long, `1` = Short | `0` (Long) |
| Thumb size | Thumbnail size in thumbnail mode | `0` = Large, `1` = Medium, `2` = Small | `1` (Medium) |

> **Recommended**: Detail mode (default) provides the most information.

## History

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| History info size | Maximum number of history entries to keep | 100 / 500 / 1000 / 5000 / 10000 / 20000 | 100 |

> **Recommended**: 1000 (good balance of storage and recall).

## Thumbnails

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Manual thumb resolution | Enable manual thumbnail resolution setting | true / false | false |
| Custom thumb resolution | Set thumbnail resolution manually (px) | 100–500 | 250 |
| Fix thumb URL | Fix thumbnail loading failures | true / false | false |

> **Recommended**: Keep manual resolution off (auto works well). Enable Fix thumb URL if thumbnails fail to load.

## Gallery Display

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Show Japanese title | Prefer Japanese titles over English | true / false | false |
| Show gallery pages | Display page count in the gallery list | true / false | false |
| Show loading speed | Show image loading speed info | true / false | false |
| Show tag translations | Show Chinese translations of tags | true / false | true |
| Tag translations source | URL for tag translation data | — | Mapaler's translation library |

> **Recommended**: Enable Show gallery pages (useful) and Show tag translations (recommended).

## Filters & Comments

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Filter | Manage title/uploader/tag filter rules | — | — |
| Show gallery comments | Display the comments section below galleries | true / false | true |
| Enable comment rating filter | Filter comments by rating | true / false | false |
| Comment rating threshold | Comments below this score are hidden | -100 to 100 | 0 |
| Show gallery rating | Display the star rating of galleries | true / false | true |
| Blacklist | Manage the blacklist | — | — |

> **Recommended**: Keep comments and ratings visible. Enable comment rating filter only if needed.
