## Common Search Syntax

E-Hentai supports a rich set of search operators. Here are some common examples:

| Syntax | Description | Example |
|--------|-------------|---------|
| `keyword` | Search for keywords | `fate grand order` |
| `"exact phrase"` | Match an exact phrase | `"big breast"` |
| `keyword1 keyword2` | Match all keywords (AND) | `ahegao swimsuit` |
| `keyword1 OR keyword2` | Match either keyword (OR) | `elf OR orc` |
| `-keyword` | Exclude a keyword | `fate -apocrypha` |
| `language:chinese` | Filter by language | `language:chinese` |
| `uploader:name` | Filter by uploader | `uploader:sample` |
| `tag:namespace:value` | Search by tag | `tag:character:saber` |
| `min_pages:N` | Minimum page count | `min_pages:50` |
| `max_pages:N` | Maximum page count | `max_pages:200` |

> For more detailed syntax, tap "Search Syntax Help" inside the app.
