# Privacy Settings

> Pattern protection, secure mode, and data collection settings.

| Name | Description | Possible Values | Default |
|------|-------------|-----------------|---------|
| Pattern protection | Set up a pattern lock to protect the app | — | — |
| Enable secure mode | Enable secure mode (hides app content) | true / false | false |
| Enable analytics | Allow collection of anonymous usage data | true / false | true |
| About analytics | View the analytics disclosure | — | — |

> **Recommended**:
> - Set up pattern protection as needed to safeguard your privacy.
> - Enable secure mode when you need to hide content.
> - Disable analytics for better privacy.
