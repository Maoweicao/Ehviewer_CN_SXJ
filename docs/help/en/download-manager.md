# Download Manager

<!-- screenshot: docs/help/en/download-hero.png -->

The download manager lets you queue, organize, and track gallery downloads. It supports labels, filtering, sorting, drag-and-drop reordering, and batch operations.

---

## Accessing Downloads

Open the **navigation drawer** and tap **Downloads** (⬇️ icon).

The download screen shows all your queued and completed downloads, organized by labels.

---

## Downloading a Gallery

1. Open a gallery's **detail page**.
2. Tap the **Download** button to start downloading immediately.
3. **Long-press** the Download button to choose a download label/category first.

### Batch Download

1. On the gallery list, **long-press the FAB** to enter multi-select mode.
2. Tap galleries to select them.
3. Use the FAB menu to download all selected galleries at once.

---

## Download Labels

Labels help you organize downloads into categories (similar to folders).

### Managing Labels

- Open the **right-side drawer** on the Downloads screen to see all labels.
- Create, rename, or delete labels from the drawer.
- Each label shows a count of downloads it contains.

### Assigning Labels

- When downloading (long-press Download button), choose a label from the list.
- Move existing downloads between labels via the long-press context menu.

## Filtering Downloads

Use the **toolbar menu** to filter downloads:

### By Status

| Filter | Description |
|--------|-------------|
| All | Show everything |
| Completed | Finished downloads only |
| Not Started | Queued but not yet downloading |
| Waiting | Waiting for a download slot |
| Downloading | Currently active |
| Failed | Downloads that encountered errors |

### By Category

Filter by the gallery's E-Hentai category:

| Category | Description |
|----------|-------------|
| All | No category filter |
| Misc | Miscellaneous |
| Doujinshi | Doujinshi (self-published) |
| Manga | Manga |
| Artist CG | Artist CG sets |
| Game CG | Game CG sets |
| Image Set | Image sets |
| Cosplay | Cosplay photos |
| Asian Porn | Asian content |
| Non-H | Non-adult content |
| Western | Western content |
| Unknown | Uncategorized |

## Sorting Downloads

Access sorting options from the toolbar menu:

| Sort Option | Direction | Description |
|-------------|-----------|-------------|
| Default | — | Order added |
| Gallery ID | Ascending / Descending | By E-Hentai gallery ID |
| Created Time | Ascending / Descending | When added to downloads |
| Rating | Ascending / Descending | By gallery rating |
| Name | Ascending / Descending | Alphabetical by title |
| Size | Ascending / Descending | By file size |

## Toolbar Actions

| Action | Description |
|--------|-------------|
| Sort/Filter | Open sorting and filtering sub-menus |
| Start All | Resume all paused/queued downloads |
| Pause All | Pause all active downloads |
| Reset Reading Progress | Clear reading progress for all downloads |
| Search Downloads | Search within your download list |
| Import Local Archive | Import ZIP/CBR files from local storage |

---

## Individual Download Actions

### Tap

- **Incomplete download**: Opens the gallery detail page.
- **Completed download**: Opens the reader at your last-read position.

### Long-Press

Long-press a download to open a context menu with a thumbnail preview and tag chips:

| Action | Description |
|--------|-------------|
| View Details | Open the gallery detail page |
| Move to Label | Move to a different download label |
| Delete | Remove the download (optionally delete files) |
| Resume/Retry | Restart a failed or paused download |

### Drag and Drop

Reorder downloads within a label by **long-pressing and dragging**. This changes the download priority — items at the top download first.

---

## Pagination

When you have many downloads, the list is paginated for performance:

| Setting | Options |
|---------|---------|
| Items per page | 50 / 100 / 200 / 300 / 500 |

A pagination indicator appears at the bottom of the list. Configure this in **Settings → Download**.

---

## Unread Count

The Downloads section in the navigation drawer shows a **badge** with the number of newly completed downloads you haven't viewed yet.

---

## Compression & Export

You can compress downloaded galleries to save storage:

1. Enter multi-select mode on the Downloads screen.
2. Select the galleries you want to compress.
3. Use the action menu to start compression.

---

## Progress Tracking

- Each download shows a **progress bar** with percentage.
- The notification area shows overall download progress (if notifications are enabled).
- Failed downloads display an error icon — long-press to see the error details and retry.
