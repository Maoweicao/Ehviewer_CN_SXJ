# Favorites

<!-- screenshot: docs/help/en/favorites-hero.png -->

The Favorites section lets you save and organize galleries into folders for easy access. You have **10 cloud-based favorites folders** (synced with your E-Hentai account) and **1 local folder** stored on your device.

---

## Accessing Favorites

Open the **navigation drawer** and tap **Favorites** (❤️ icon).

The screen shows galleries saved in the currently selected folder. Use the **right-side drawer** to switch between folders.

---

## Favorites Folders

### Cloud Favorites (10 folders)

These are synced with your E-Hentai account and accessible from any device or browser:

| Folder | Description |
|--------|-------------|
| Favorites 0–9 | 10 customizable folders (named on E-Hentai website) |

Cloud favorites count against your E-Hentai favorites limit and are visible on the E-Hentai website.

### Local Favorites (1 folder)

| Folder | Description |
|--------|-------------|
| Local | Stored only on your device — not synced with E-Hentai |

Use local favorites for galleries you want to keep private or offline.

### Viewing All Cloud Favorites

Select **All Cloud** from the right-side drawer to see galleries from all 10 cloud folders combined.

---

## Folder Selector

Open the **right-side drawer** on the Favorites screen to access the folder selector:

| Element | Description |
|---------|-------------|
| Cloud folders (0–9) | Each shows a gallery count badge |
| Local folder | Device-only storage |
| Default folder setting | Set which folder is used by default when favoriting |

## Adding a Gallery to Favorites

### From Gallery Detail Page

1. Open a gallery's detail page.
2. Tap the **heart icon** or the **favorite action** in the FAB menu.
3. Choose a folder (or use the default if one is set).

### From Gallery List (Batch)

1. **Long-press the FAB** on the gallery list to enter multi-select mode.
2. Tap galleries to select them.
3. Use the FAB menu to add all selected galleries to a favorites folder.

---

## Setting a Default Folder

You can set a default favorites folder so you don't have to choose every time:

1. Open the right-side drawer on the Favorites screen.
2. Tap the **settings/menu** option at the bottom.
3. Choose your default:

| Option | Behavior |
|--------|----------|
| Let me choose | Show folder picker every time (default) |
| Local | Always save to local favorites |
| Favorites 0–9 | Always save to the chosen cloud folder |

---

## Searching Favorites

Use the **search bar** at the top of the Favorites screen to search within the current folder:

1. Tap the search bar.
2. Type keywords.
3. Results are filtered to the currently selected folder.

The search bar title shows: **Folder Name — Search Term**

---

## Managing Favorites

### Single Gallery

| Action | How | Description |
|--------|-----|-------------|
| View | Tap | Open gallery detail page |
| Context Menu | Long-press | Show options menu |
| Move | Long-press → Move | Move to a different folder |
| Remove | Long-press → Remove | Remove from favorites |
| Download | Long-press → Download | Add to download queue |

### Batch Operations

1. **Long-press the FAB** to enter multi-select mode.
2. Tap galleries to select them.
3. Use the expanded FAB menu:

| Batch Action | Description |
|--------------|-------------|
| Move | Move all selected to another folder |
| Remove | Remove all selected from favorites |
| Download | Download all selected galleries |

---

## First-Time Guide

When you first open the Favorites section, a **showcase overlay** appears explaining how to use the right-side drawer to manage your folders. This only shows once.

---

## Tips

- **Sync across devices**: Cloud favorites sync with your E-Hentai account, so they're available on any device where you log in.
- **Organize by type**: Use different cloud folders for different genres or reading status (e.g. "To Read", "Completed", "Favorites").
- **Local for privacy**: Use the local folder for galleries you don't want linked to your E-Hentai account.
- **Quick favorite**: Set a default folder in settings to favorite galleries with a single tap.
