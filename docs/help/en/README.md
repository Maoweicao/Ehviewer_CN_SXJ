## Overview

Welcome to the **EhViewer CN SXJ** help documentation! This guide covers all major features and settings of the application, helping you get started quickly and make the most of it.

**EhViewer CN SXJ** is an E-Hentai browser designed for Android, featuring a Chinese-localized interface. It supports gallery browsing, search, download management, favorites, browsing history, and much more.
